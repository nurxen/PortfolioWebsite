Optimization Techniques

Static Batching
Grouped meshes sharing materials. Allowed the GPU to render in combined batches rather than thousands of individual calls.
>>>>>>> Green-Vanilla
Texture Atlasing
Combined multiple object textures into unified atlases, drastically dropping state changes and SetPass overhead (2.5k → 31).
Mesh Collider Removal
Replaced overly complex mesh colliders with simplified primitive Box Colliders to minimize physics overhead.
Baked Lighting
Pre-calculated illumination and utilized Light Probes for dynamic elements, eliminating real-time per-frame calculations.

Channel Packing Benefits

60% Texture Memory Reduction
Combines Metallic (R), Ambient Occlusion (G), Roughness (B) in single RGBA texture. Bandwidth savings verified with Unity Profiler.
Single Texture Sample
GPU reads one file instead of three. Reduces fragment shader instructions. Improves cache locality.
Scalable Asset Pipeline
New objects integrate into existing atlas without increasing draw calls or SetPass calls. Future-proof architecture.
